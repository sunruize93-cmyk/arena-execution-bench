## 小红书

**标题：AI 会付钱，但会不会付两遍？**

付款没确认，AI 会等一等，还是再付一次？

我开源了 Arena Execution Bench，给 Agent 做了个「花钱测试场」：用模拟钱测试重复付款、低价高风险、预算被占用这些问题。

内置示例不用钱包、GPU 或模型 API key。做 Agent 的朋友可以直接拿来比较策略、回放账本，少搭一套测试环境。

Apache-2.0 开源。欢迎试用、提 Issue，也欢迎给个 Star ⭐

https://github.com/sunruize93-cmyk/arena-execution-bench

## LinkedIn

Before an AI agent spends real money, how do you test its payment decisions?

I open-sourced Arena Execution Bench: a local sandbox for testing payment retries, provider fees and locked budgets with simulated money.

Compare policies, replay transactions, and reproduce failures. The built-in demo needs no wallet, GPU or model API key.

My goal is simple: give agent developers a reusable test environment. Apache-2.0. Feedback, new scenarios and contributions are welcome.

https://github.com/sunruize93-cmyk/arena-execution-bench
